# AgentMentor Evidence

Bind an important statement to what was actually checked.

1. State the claim and its verification boundary before writing Evidence.
2. Create `docs/evidence/EV-xxx-*.md` from `assets/templates/EVIDENCE.md` only when durable proof is useful.
3. Record commands, test names, manual checks, artifacts, results, and limitations; do not paste every transient test log.
4. Link the owning Feature and run the strict knowledge check after editing the artifact.

Evidence does not explain design rationale or future work plans.
