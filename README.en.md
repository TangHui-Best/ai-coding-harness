# AgentMentor

[简体中文](README.md)

AgentMentor vNext is an engineering-memory, Feature-level SDD, and verification-constraint layer for capable coding agents. It is not a default multi-gate development pipeline.

It retrieves one bounded context package at task start, then lets the model plan, implement, test, and collaborate normally. Intent, decision, learning, evidence, and closeout skills trigger only when their corresponding engineering event occurs.

The six installed skills are `agentmentor`, `agentmentor-intent`, `agentmentor-decision`, `agentmentor-learning`, `agentmentor-evidence`, and `agentmentor-closeout`.

`v1.0.0` remains the stable historical baseline. The `vnext` branch is the incompatible `v2.0.0` redesign and must demonstrate retrieval quality and workflow efficiency on real tasks before release.
