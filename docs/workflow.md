# Workflow

The recommended harness loop:

1. Retrieve relevant project context.
2. Clarify the user goal and constraints.
3. Execute the smallest coherent change.
4. Verify with concrete evidence.
5. Capture durable knowledge only when future work would benefit.
6. Write a compact change narrative for review, handoff, or history.

The loop should stay lightweight. Harness is not a documentation tax; it is a way to prevent repeated rediscovery and unverifiable completion.
